Panel Inspector Pro

A field engineer points their phone at an LV switchboard and takes a photo — that single action triggers a full inspection:

  • → The Android app (Kotlin) captures the image with GPS coordinates, stores the scan in local SQLite, and sends it to the backend.
  • → My Python FastAPI backend runs a computer vision pipeline: identifies the panel model (PrismaSeT G / P or Okken), draws bounding boxes around every circuit breaker, and reads each breaker's rating and label.
  • → A safety checklist is auto-generated — IEC 60900, arc-flash PPE, and Schneider-specific procedures — based on the panel type and breakers detected.
  • → Engineers can upload a Single Line Diagram (PDF or image) for cross-referencing against the detected breakers.
  • → The same backend powers a public web platform — no app install needed, deployed on Render and live 24/7.

About this role

As part of my Master's internship at Schneider Electric Grenoble, I was tasked with building an intelligent inspection tool for field engineers working with Schneider Electric LV switchboards. The project required deep knowledge of both the electrical products and modern AI techniques.

The result — Panel Inspector Pro — is a fully deployed Android app and web platform that uses Google Gemini AI to automatically identify panel types, detect circuit breakers, read ratings, and generate safety checklists aligned with IEC standards and Schneider's own catalogue.

Key Contributions
  • Built an Android application (Kotlin) for on-site LV panel scanning with camera, GPS, and offline SQLite storage.
  • Designed a Python FastAPI backend with a computer vision pipeline for automatic panel classification and breaker detection with bounding boxes.
  • Developed a public web platform accessible to clients, deployed on Render cloud — no installation needed.
  • Implemented Single Line Diagram (SLD) cross-referencing — accepts PDF or image formats, sent directly to the AI model.
  • Created task-specific safety checklists based on IEC 60900 and Schneider's arc flash guidelines (PrismaSeT G, PrismaSeT P, Okken).
  • Integrated GPS location verification and scan history with full SQLite persistence.
